# KA-PAMANA presentation kit

Prepared for Abao, Mathew Andrei F.; Araño, John Christopher C.; and Palpallatoc, Mica V. of BSIT 4-5.

The `output` folder contains:

- `KaPamana_Chapters_1_and_3_Print.pdf` — print-ready Chapters 1 and 3 on 8.5 × 13 inch long bond paper. Review any school-specific formatting rule before printing copies for each subject.
- `KaPamana_Chapters_1_and_3.docx` — editable copy of the same documentation.
- `KaPamana_Project_Presentation_Ready.pptx` — six-slide title and features presentation.
- `KaPamana_Feature_Video_Ready.mp4` — a 72-second offline feature overview with music. It is a visual presentation, not footage of a live phone session. The runbook includes optional narration.
- `Demo_Runbook.md` — rehearsal, primary and backup internet, live sequence, and fallback steps.

Install the latest successful Android debug APK from [the build workflow](https://github.com/cedimscalapan/bp/actions/workflows/android-apk.yml) on a phone before the presentation. GitHub may require sign-in to download the artifact. Store the APK, MP4, and PPTX locally before the session.
